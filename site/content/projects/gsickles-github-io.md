**Tech:** Rust, Declarative Macros, Vanilla JS

A custom HTML templating system built with Rust macros. Features:
- Declarative syntax for writing HTML
- Compile-time asset inclusion
- Type-safe HTML generation
- Zero runtime dependencies

The entire site is generated from clean, readable Rust code into a single self-contained HTML file.

[View the showcase page](showcase.html) to see all available HTML tags and examples. [View the raw HTML](https://raw.githubusercontent.com/gsickles/gsickles.github.io/main/showcase.html) to see the pretty formatting.
